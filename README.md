# KupiDonat

Вёрстка выбранного экрана Figma `2028:34777` из файла `rYl2Zh92xqBj6BZj9TnTxR`.

## Онлайн

- [KupiDonat](https://jenya-martynenko.github.io/sofl/)
- [OneWhale](https://jenya-martynenko.github.io/sofl/onewhale.html)

## Просмотр

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Откройте http://127.0.0.1:4173. Сборка и установка зависимостей не нужны.

## Состав

- `index.html` — семантическая разметка экрана, живой текст, форма поиска.
- `styles.css` — стили и адаптация для узких экранов.
- `app.js` — фокус поиска, обработка формы, обратная связь кнопок.
- `assets/` — локальные шрифты, оригинальные иконки и декоративные слои Figma. Сложные фоновые слои экспортированы с прозрачностью; это не скриншот интерфейса.
- `reference/figma.png` — исходный фрейм 1440 × 1005.
- `reference/desktop.png` и `reference/width-*.png` — снимки локальной страницы в Chrome.
- `reference/browser-check.json` — результат проверки браузера.

## Границы реализации

Включён выбранный фрейм высотой 1005 px: шапка, заголовок, поиск и статистика. Нижние секции исходного файла находятся за пределами этого фрейма. Мобильная компоновка адаптирована самостоятельно: отдельного мобильного макета в задании нет.

Шрифты Poppins и Inter подключены локально. В Figma у статистики указан **Neue Haas Grotesk Display Pro**, но API подтверждает `hasMissingFont: true`. Для живого текста статистики использована близкая системная замена Arial; точное совпадение этих глифов с сохранённым изображением Figma не гарантируется. Для окончательной типографической идентичности нужен исходный веб-шрифт. Сглаживание текста также зависит от браузера и платформы.

Поиск, маршруты разделов и авторизация не подключены к сервисам. Кнопки показывают честное сообщение о недоступности. Для интеграции предусмотрены отменяемые события `kupidonat:search` (`detail.query`) и `kupidonat:navigate` (`detail.destination`); обработчик может вызвать `event.preventDefault()`, чтобы подавить сообщение.

## Проверка

### Демо подсказок

Введите `wo`: поиск раскрывается по состоянию Figma `2028:34294`, с затемнением и размытием фона. Используются пять локальных примеров: World of warcraft, World of Warships, World of Tanks, World War Z: Aftermath и Wolfenstein. Фильтрация не зависит от регистра. Выбор работает кликом и стрелками ↑/↓ с Enter; Escape и клик снаружи закрывают подсказки. Очистка сбрасывает ввод. Это демонстрационные данные, а не реальная история пользователя; выбор пока только заполняет поле и отправляет событие `kupidonat:search`.

Снимки состояния: `reference/search-desktop.png` и `reference/search-mobile.png`. Проверены выбор мышью и клавиатурой, отсутствие совпадений, очистка, закрытие и мобильная компоновка.

Проверено в Chrome: 1440 × 1005, ширины 390, 768 и 1024 px; загрузка всех изображений, отсутствие ошибок JavaScript и горизонтального скролла, фокус поля, ввод, отправка формы, закрытие сообщения клавишей Escape.

`reference/check.py` — воспроизводимая проверка через Python Playwright; на этой машине использован отдельный QA venv в `/private/tmp/kupidonat-qa`. Основной сайт от него не зависит.
